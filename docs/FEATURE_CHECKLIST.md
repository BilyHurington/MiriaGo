## I. 导入导出

- [ ] `=` 摘要：计划名、「{g} 个片区 / {p} 个点位」

- [ ] `=` 数据包选项：「纯计划 / 计划+记录」（窄屏时竖向排列）、「包含完整参考图缓存」；包大小估算有 3 种状态
- [ ] `=` 导出流程：
  1. 提示「正在导出...」，加载记录。
  2. 有资源缺失时确认（「部分本地资源缺失」→「继续导出」）。
  3. 选择保存位置（桌面和 Tauri 先选）。
  4. 生成数据包（可取消）。
  5. 交付：移动端分享，桌面保存，Web 下载。
  6. 结果提示，缺失资源按类别统计。
- [ ] `=` 导出中按返回会取消导出，并提示「已取消导出」
- [ ] `=` My Maps CSV：交付后提示「My Maps CSV 已导出」；有 N 个没有坐标的点位时给出警告
- [ ] `=` 导入预览：
  - 包信息与统计。
  - 3 项导入选择，说明文字随包内容和平台能力变化。
  - 「包内提示」最多 6 条。
  - 导入流程：恢复资源 → 重写路径 → `importPlanPackage` → 确认恢复结果。
  - 结果提示 3 种；失败时只在确认安全后删除已恢复的资源。
